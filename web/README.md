# Team Directory + Issues (web)

Vite + React + TypeScript app: a searchable team directory (`#/team`) and a basic Linear-style issue tracker for the same people (`#/issues`). See the [root README](../README.md) for how to run it and what was tested, and [SPEC.md](SPEC.md) for the feature spec.

```bash
npm install && npm run dev
npm test
```
